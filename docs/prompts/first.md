
I want to make a simple Window app called "Tell Me When You See This Change" that acts like a small utility, like Snipping Tool. The use case I have in mind is Control Engineers, who sometimes need to know when something on their screen changes while they are a few feet away from their computer, flagging a prox or something

I want the user to be able to pick a single pixel from the screen. The selector should magnify kind of like how Snagit works, with a pixel magnifier. 

Once the pixel is selected, the user can arm the alert. Once armed, the program should just emit a tone when the pixel changes to anything other than the color it was when selected.

Stylistically, it should be minimalist, but perhaps a touch industrial (steam punk perhaps?)
